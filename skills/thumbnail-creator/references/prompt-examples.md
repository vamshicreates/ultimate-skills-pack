# Thumbnail Prompt Examples

## High-Performing Prompt Patterns

### Reaction/Emotion Thumbnails
```
A [person description] with [extreme emotion] expression, [specific pose].
[Background description]. [Text overlay with exact words].
[Style: photorealistic/illustrated]. [Lighting description].
```

**Example:**
```
A young man with shocked wide eyes and jaw dropped, hands on cheeks.
Blurred city background with golden light. Bold white text "NO WAY"
in top right corner. Photorealistic, cinematic lighting with lens flare.
```

### Before/After Thumbnails
```
Split image: left side shows [before state], right side shows [after state].
Clear dividing line with [arrow/text]. [Subject consistent across both].
High contrast, clean composition.
```

**Example:**
```
Split thumbnail: left side shows messy cluttered desk with stressed person,
right side shows minimalist organized workspace with same person smiling.
Red arrow pointing right between them. Text "30 DAYS" at bottom.
Clean, bright lighting on both sides.
```

### Tutorial/How-To Thumbnails
```
[Main subject/product] in center, [person pointing or gesturing at it].
[Step numbers or key benefit as text]. Clean background with [brand colors].
Professional, educational feel.
```

**Example:**
```
MacBook Pro displaying code editor in center, confident developer
pointing at screen with smile. Text "5 TRICKS" in bold red at top.
Clean white studio background, soft professional lighting.
```

### Listicle/Number Thumbnails
```
Large bold number [X] as focal point, surrounded by [related imagery].
[Subject reacting to or presenting the content]. Vibrant colors,
high energy composition.
```

**Example:**
```
Giant "10" in 3D metallic gold, floating above pile of money.
Excited person in corner with pointing gesture. Dark gradient
background with money flying. Vegas-style lighting.
```

### Controversy/Drama Thumbnails
```
Two opposing [people/things] facing each other with [tension].
Versus or conflict imagery. [Dramatic text]. High contrast,
dramatic lighting, cinematic feel.
```

**Example:**
```
Two tech CEOs facing each other in profile, tense expressions.
Lightning bolt between them. Text "THE FIGHT" in bold red.
Dark stormy background, dramatic rim lighting on faces.
```

### Transformation/Results Thumbnails
```
[End result/achievement] prominently displayed. Person showing
[pride/excitement]. [Metric or proof] as text overlay.
Aspirational, motivating mood.
```

**Example:**
```
Fit person flexing in mirror with confident smile, before photo
small in corner showing overweight. Text "$0 GYM" in bold.
Gym background, motivational lighting.
```

## Style Modifiers

### Photorealistic
- "photorealistic, 8k quality, professional photography"
- "DSLR photo, shallow depth of field, bokeh"
- "studio lighting, commercial photography style"

### Illustrated/Artistic
- "digital illustration, vibrant colors, cartoon style"
- "3D rendered, Pixar-style, playful aesthetic"
- "anime style, dynamic pose, colorful"

### Cinematic
- "cinematic, movie poster style, dramatic"
- "film grain, anamorphic lens, Hollywood quality"
- "epic scale, theatrical lighting"

### Clean/Minimal
- "clean composition, minimal design, modern"
- "flat design, bold colors, simple background"
- "whitespace, professional, corporate"

## Text Overlay Best Practices

### Effective Text Placement
- Top third: Works well for main hooks
- Bottom third: Good for context/numbers
- Corners: Ideal for secondary info
- Center: Only for single powerful word/number

### Text Styling
```
Bold [color] text saying "[exact words]" in [position].
[Font style] with [effect: shadow/outline/glow].
```

**Examples:**
```
Bold yellow text saying "WATCH THIS" in top left corner,
thick black outline for readability.
```

```
Large red "WARNING" centered, white glow effect,
slightly tilted for urgency.
```

## Common Mistakes to Avoid

1. **Too much text** - Keep to 3-5 words maximum
2. **Low contrast** - Text must pop against background
3. **Cluttered composition** - One clear focal point
4. **Generic expressions** - Exaggerate emotions
5. **Boring backgrounds** - Add depth and interest
6. **Tiny faces** - Faces should be at least 1/3 of thumbnail
