# PitchBlu Carousel

Reusable skill for turning a person's supplied professional screenshots, portrait, and work samples into an evidence-based six-slide Canva carousel based on the Satish PitchBlu design.

Invoke it when you share a person's screenshots and ask for the PitchBlu carousel, profile carousel, cover/body/CTA copy, image placement, or final edited design.

The skill is in `SKILL.md`. `references/canva-template.md` records the design link, six-slide story, and image mapping. For each person it creates a `PitchBlu Carousel/<person-slug>/` workspace with source, selected images, final copy, and image-placement notes.
