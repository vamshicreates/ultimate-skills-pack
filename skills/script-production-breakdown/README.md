# Script Production Breakdown

Codex agent skill for turning a locked screenplay into a scene inventory, production breakdowns, continuity notes, and 3×3 storyboard sheets.

## How to use

1. Clone this repository or add it to your Codex skills directory. Open [SKILL.md](SKILL.md) for the full workflow.
2. Provide the locked screenplay as PDF, DOCX, FDX, Fountain, or TXT. Identify the authoritative revision if several copies exist.
3. Request a **pilot** for two or three representative scenes, a **full** breakdown, or **selected scenes**. Example: “Use Script Production Breakdown on this screenplay for a pilot.”
4. Review the complete scene inventory, source references, continuity questions, production requirements, and one 3×3 storyboard per finished scene.
5. Resolve flagged script or production uncertainties before using the output for planning.

The default pilot indexes the whole script but finishes only representative scenes. See the [breakdown schema](references/breakdown-schema.md) for deliverable fields.
