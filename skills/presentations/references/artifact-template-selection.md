# Reference discovery and selection

Before designing a new presentations, search the user's relevant connected sources for previous presentations. Automatically reuse the strongest suitable previous presentations and proceed without asking for confirmation.

Skip discovery when the user has already chosen a reference or template, explicitly requested a fresh design, or declined reuse. If the user explicitly asks to choose the reference, recommend the strongest fit and ask: "Which previous presentations should I base this on?" Label each option with its title and wait for their choice.
First search for previous presentations on the topic. If that finds no suitable presentations, broaden to presentations with a similar purpose or audience from the user or team.

Search outward, stopping when suitable candidates are found:

1. The user's most recent presentations on the same topic, including the same recurring series. Prefer presentations they created or contributed to.
2. Their team's presentations on the same topic and type.
3. presentations with a similar purpose or audience, first from the user, then their team.

Within each group, rank by fit and prefer the latest suitable version. Briefly identify the selected reference by its title and source link before proceeding.

If the search finds no suitable previous presentations, continue from the user's request with a fresh design. Do not search generic templates as a fallback.
