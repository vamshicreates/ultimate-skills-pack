# Iman Gadzhi Style Editing (`iman-gadzhi-style-editing`)

> Premium personal-brand videos with luxury lifestyle B-roll, 3D finance assets, film burns, and high-retention pacing.

A production-grade Agent Skill compatible with **Claude Code, Antigravity, Cursor, Windsurf, OpenCode, Codex**, and video editing workflows (Premiere Pro, After Effects, DaVinci Resolve, Remotion, FFmpeg).

## What This Skill Does

This skill equips AI coding agents with the exact visual grammar, cut frequency, motion physics, color palettes, typography specifications, and audio engineering rules to recreate the signature **Iman Gadzhi Style Editing** aesthetic.

See [`SKILL.md`](SKILL.md) for the full technical breakdown, expressions, and execution recipes.

## Installation

### Method A: Install in Claude Code (`~/.claude/skills`)

**macOS / Linux:**
```bash
mkdir -p ~/.claude/skills/iman-gadzhi-style-editing
git clone https://github.com/vamshicreates/iman-gadzhi-style-editing.git ~/.claude/skills/iman-gadzhi-style-editing
```

**Windows (PowerShell):**
```powershell
New-Item -ItemType Directory -Force -Path "$HOME\.claude\skills\iman-gadzhi-style-editing"
git clone https://github.com/vamshicreates/iman-gadzhi-style-editing.git "$HOME\.claude\skills\iman-gadzhi-style-editing"
```

### Method B: Install in Cursor / Antigravity / Agent Workspace (`.agents/skills`)

**macOS / Linux:**
```bash
mkdir -p .agents/skills/iman-gadzhi-style-editing
git clone https://github.com/vamshicreates/iman-gadzhi-style-editing.git .agents/skills/iman-gadzhi-style-editing
```

**Windows (PowerShell):**
```powershell
New-Item -ItemType Directory -Force -Path ".agents\skills\iman-gadzhi-style-editing"
git clone https://github.com/vamshicreates/iman-gadzhi-style-editing.git ".agents\skills\iman-gadzhi-style-editing"
```
